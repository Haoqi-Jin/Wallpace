# Wallpace 故障排查手册

> 出问题了先看这里。绿色版 `wallpace\` 目录内自带本手册（`故障排查.md`）与使用指南（`使用说明.md`）。
> 每条按「现象 → 原因 → 怎么办」组织。找不到对应条目时，最后一节教你**自己捞日志**报给我们。

---

## 1. 看日志（万能第一步）

日志都在 `~/.wallpace/logs/`（`~` 是你的用户目录，Windows 上即 `%USERPROFILE%\.wallpace\logs\`），
主文件 `wallpace.log`（自动轮转：单文件 1MB，最多保留 3 个备份 `wallpace.log.1~.3`，不会无限涨）。

**两个入口（任选）：**

- 托盘图标 **右键 → 「打开日志目录」**
- 「设置 → 打开日志目录（诊断）」按钮

两个入口都会用文件管理器打开日志目录；若打不开，弹窗里会直接写出目录路径让你手动进。

> 建议：排查时**开着日志目录窗口**，操作出问题后刷新就能看到新日志行（`INFO` 正常、`WARNING` 注意、
> `ERROR`/`CRITICAL` 出事了）。

## 2. 常见现象速查

### 「壁纸切换失败」气泡（托盘弹出来一条）

**现象**：右下角弹出 `壁纸切换失败（xxx.jpg）` 的气泡。
**原因**：这次随机选到的图片打不开（文件被删了、损坏了、或磁盘抽风）。
**实际发生了什么**：程序**不会**停下来——它最多自动换 3 张互不相同的候选图依次重试，
只有 **3 张全失败**才弹这条气泡（`scheduler` 的兜底逻辑）。
**怎么办**：
- 大多数情况**不用管**，下一张/下一次切换就恢复了。
- 若反复弹：去图库里把那张坏图「跳过」，或确认文件夹里的图片没被杀毒软件隔离。

### 点了「换一张」没反应

按顺序排查：

1. **暂停了？** 托盘文案/顶栏显示「已暂停」时，左键点托盘是不动的。右键 → 「继续切换」。
2. **正在扫描？** 大目录首次扫描时「换一张」被禁用，等扫描完（进度提示消失）再点。
3. **图库是空的？** 还没添加文件夹或没扫到图 → 「设置 → 添加图片文件夹」。
4. **真失败了？** 没气泡也没换 → 去日志搜 `ERROR`，通常是该图文件打不开。

### 程序没在跑 / 托盘里没图标

- 你「退出」了或系统还没开机自启。
- **开机自启默认是关的**：想开机自动跑，去「设置 → 开机自启」勾选（程序写 `HKCU\...\Run`）。
- 若你之前装过旧版后又删了 exe：重新运行一次，程序会**自动清理指向旧 exe 的坏自启项**（自愈），
  再勾选一次开机自启即可。

### 双击报 `Failed to load Python DLL ...\_internal\python313.dll`

完整报错通常是：

```
Failed to load Python DLL 'C:\Users\<你>\Desktop\_internal\python313.dll'.
LoadLibrary: 找不到指定的模块。
```

**原因**：绿色版是 **onedir（目录形态）**。`wallpace.exe` 只是启动器，真正的依赖
（Python DLL、Qt 等）都在同目录的 `_internal\` 文件夹里。只把 `wallpace.exe`
一个文件复制到桌面 / 发给别人，它就找不到 `_internal\`，直接启动失败。

**解决**：

- 复制/分发时带上**整个 `wallpace\` 目录**（exe + `_internal\` + 附带文档），
  双击目录里的 `wallpace.exe`。
- 想要桌面入口：右键 `wallpace.exe` →「发送到 → 桌面快捷方式」，
  **不要**直接把 exe 拖出来。
- 目录移动过位置的话，去「设置 → 开机自启」取消再勾选一次（自启项存的是旧路径）。

### SmartScreen 提示「未知发布者」/ 杀软误报

第一次双击解压后的 `wallpace\wallpace.exe`，Windows SmartScreen 可能弹「已保护你的电脑 / 未知发布者」：
本工具**不做代码签名**（小圈子分发场景，按拍板不付费买证书），这是正常现象，不是病毒——
点「更多信息 → 仍要运行」即可，之后不再提示。

- 旧版（UPX+单文件 exe）时期杀软误报率偏高；现已改 **onedir + 去 UPX** 产物（`dist/wallpace/` 目录），误报大幅减少。
- 若你的杀软仍拦截：把解压目录加入信任区/白名单。
- 判断真假的依据：来源是你信任的朋友给的 zip；exe 在 `wallpace\` 目录下且旁边有依赖文件（onedir 特征），而不是一个孤立的 48MB 单文件。

### 多屏时有的屏没换 / 重启后逐屏设置「丢了」

- 程序重启会恢复上次保存的逐屏分配，但**已拔掉/拔线的显示器**、**已删除的图片**会被自动剔除，
  对应屏回退为「所有屏同一张」。这是预期行为，不是 bug。
- 环境不支持逐屏（如远程桌面、部分虚拟机）时也会回退统一壁纸，并在日志里记一条降级说明。

### 壁纸一直不变

1. 当前是「手动」模式吗？手动模式只有你点「换一张」才变。
2. 是「每日随机」吗？模式就是**一天一张**，不到点不换（属正常）。
3. 「间隔时间」模式？确认分钟数 > 0（0 或空会被兜底成 60，日志里有记录）。

### 收藏/跳过没生效

- 收藏（☆）与「跳过」只影响**下一次随机**，不会立刻换图。
- 全部图都被跳过了 → 图库不可用，会像「没有图」一样。去「已跳过」筛选里恢复（取消跳过）。

## 3. 配置损坏了，怎么找回

**现象**：启动时弹窗提示配置损坏/已重置。
**程序做的事**（自动，不用你操心）：

1. 把坏文件**原样备份**为 `config.json.corrupt-YYYYMMDD-HHMMSS`（不会删原文件）。
2. 用出厂默认值重置一份新配置，程序正常启动。

**怎么找回数据**：

- 备份文件在 `~/.wallpace/` 下，形如 `config.json.corrupt-20261018-120000`。
- 它可能是部分可读的 JSON——用记事本打开，能救回来的 `image_directories` / 收藏 / 跳过
  可以手动填回 `config.json` 后另存为导入文件，再用「设置 → 导入配置」拉进来。
- 实在救不回来也没事：「导入配置」只覆盖配置值，**不会删除磁盘上的图片文件**。

## 4. 换机 / 重装

1. 老机器：「设置 → 导出配置」，得到 `wallpace_export.json`。
2. 拷贝到新机器（U 盘/网盘都行）。
3. 新机器装好后「设置 → 导入配置」选中该文件。
4. 注意：导出里的**目录路径与收藏/跳过是按绝对路径存的**，两边文件夹结构一致才完全对应；
   路径变了的那些图片会扫不到，需重新添加文件夹。

---

## 5. 还是不行？自己捞日志

1. 托盘右键 → 「打开日志目录」。
2. 复制 `wallpace.log`（必要时连同 `wallpace.log.1`）。
3. 把**出问题那几行**（搜 `WARNING` / `ERROR`）连同：
   - Windows 版本、Wallpace 版本号（窗口里能看到 `vX.Y.Z`）
   - 复现步骤（你点了什么、期望什么）
   一起发给我们（GitHub issue / 群）。
