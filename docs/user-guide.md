# Wallpace 使用指南

> 面向普通用户：从安装到日常使用、到卸载，一页看完。
> 遇到问题（闪退、找不到日志、切换没反应等），看 [`troubleshooting.md`](./troubleshooting.md)。

---

## 1. 安装与启动

Wallpace 是 Windows 桌面小工具，**只支持 Windows 10/11**（壁纸设置依赖 Windows 系统接口，
其他平台会安全降级为不可用）。

启动方式任选其一：

- **绿色版**：解压得到的是一个 `wallpace\` 目录（onedir 形态），进去双击 `wallpace\wallpace.exe` 即可。
  建议把整个目录放到一个固定位置（如 `D:\tools\wallpace\`），别删；
  开机自启项指向的就是这个 exe 路径。
- **源码运行**：`python src/main.py`（需 Python 3.13 + 依赖）。

程序启动后会：

1. 出现一个主窗口（图库 / 设置两个页签）。
2. 在**系统托盘**（右下角）常驻一个小图标。

关闭窗口**默认不会退出**，而是缩到托盘继续后台运行（见「设置 → 关闭窗口时最小化到托盘」），
壁纸切换照样进行。想彻底退出：托盘图标右键 → 「退出」，或在窗口里真正退出（强制退出）。

> **单实例**：同一时间只会跑一个 Wallpace。双击图标启动第二次时，会唤醒已运行的那个并静默退出，
> 不会出现两个托盘图标、两个调度器互相抢壁纸。

## 2. 第一次使用

### 2.1 添加图片文件夹

1. 打开「设置」页。
2. 点「添加图片文件夹」，选择一个目录（支持 JPG / PNG / WebP / BMP / GIF）。
3. 程序会后台扫描该目录，图片自动出现在「图库」页。

- **多个文件夹**可以都添加，库会合并展示。
- **GIF 动图**取第一帧当壁纸（桌面壁纸本身不支持动图）。
- 图库页没有图片时会显示引导文案（按你当前筛选：全部/收藏/已跳过各给不同提示），别以为它坏了。

### 2.2 选一种切换方式

「设置 → 切换方式」有三种：

| 方式 | 行为 |
|---|---|
| **每日随机**（默认） | 每天在指定时刻（默认 08:00）随机换一张；换时刻需直接编辑 `~/.wallpace/config.json` 的 `daily_time` 字段后重启 |
| **间隔时间** | 每隔你设定的分钟数换一张（填 60 = 每小时一次） |
| **手动** | 只在你想换时才换（点托盘/「换一张」） |

改模式会立即生效并写盘。选「间隔时间」时，输入分钟数后点「应用」。

### 2.3 壁纸填充方式

「设置 → 壁纸填充方式」和 Windows「个性化 → 背景」同款，5 个选项（改完立即生效，不用重启）：

| 选项 | 效果 |
|---|---|
| **填满**（默认） | 铺满屏幕，可能裁掉边缘 |
| **完整显示（留黑边）** | 整张图都显示，两侧/上下留黑边 |
| **拉伸** | 拉满，比例可能被拉变形 |
| **居中** | 原尺寸居中，四周留黑边 |
| **平铺** | 像瓷砖一样平铺满屏 |

> 选哪种主要看你的图比例。壁纸和屏幕宽高比接近时用「填满」最舒服；图很宽或很窄时用「完整显示」。

## 3. 日常操作

### 3.1 换一张

- **托盘左键点一下** → 立刻随机换一张（调度未暂停时）。
- 或 托盘右键 → 「换一张」/ 窗口内「换一张」按钮。

如果这次换到的图你**不喜欢**：

- **跳过**：把这张从随机池里剔除，下次不会再轮到它。
- **收藏（☆）**：标记为喜欢的图。
- 也可以点图库里某张缩略图**手动指定**换到那张。

### 3.2 暂停 / 继续

- 托盘右键 → 「暂停切换」/「继续切换」。
- 暂停时顶栏和倒计时会冻结成「● 已暂停 / ⏸ 已暂停（倒计时已冻结）」，此时托盘左键点不动。
- 继续后恢复原模式与计时。

### 3.3 多显示器逐屏壁纸

支持给**每个显示器设不同的图**（通过 Windows 逐屏壁纸接口）。
重启后程序会尝试恢复你保存的逐屏分配，并自动剔除已拔掉/拔线的显示器和已删除的图片。
如果你的环境不支持逐屏（单屏或系统降级），会自动回退为「所有屏同一张」。

## 4. 配置：保存、迁移、重置

「设置」页最下方提供三个按钮：

| 按钮 | 作用 |
|---|---|
| **导出配置** | 把当前设置 + 图库状态（目录/收藏/跳过）存成一个 JSON 文件（默认保存到 `%USERPROFILE%\wallpace_export.json`）。 |
| **导入配置** | 从 JSON 文件恢复设置与图库状态（换机 / 重装时把老机器的墙搬过来）。 |
| **恢复默认配置** | 把所有设置重置为出厂默认（清空目录/收藏/跳过列表）。**只重置配置值，不会删除磁盘上的图片文件**。带二次确认。 |

> 导出/导入的文件是 `{version, config, image_library}` 结构的 JSON。导入损坏的文件会弹错误提示、
> 不做半吊子改动。

## 5. 开机自启

- 默认**关闭**。首次运行不会偷偷写注册表。
- 想开机自动跑：「设置 → 开机自启」勾选。程序会写 `HKCU\...\Run` 自启项。
- 想关掉：取消勾选即可，自启项同步移除。

## 6. 卸载

程序本身是绿色版，最后删掉 `wallpace\` 目录（含 exe 与依赖文件）即可。但删目录前仍会**残留**：

1. HKCU 里的开机自启项（指向已删的目录，任务管理器里一条坏启动项）。
2. `~/.wallpace` 数据目录（配置、收藏、日志——含你的隐私数据）。

所以请**先**做「卸载清理」再删目录：

1. 「设置 → 卸载清理」。
2. 弹窗确认（不可撤销）→ 程序先移除自启项、再删除整个 `~/.wallpace`。
3. 最后删除整个 `wallpace\` 目录（exe + 依赖文件）。

> 如果你已经删了目录才发现自启项坏了别慌：下次（重新）启动程序时会自动「自愈」——
> 检测到指向已删目录的坏自启项并清理掉。

## 7. 常见问题速查

出问题的排查手册（看日志、解释那条「切换失败」气泡、配置损坏找回等）在
[`troubleshooting.md`](./troubleshooting.md)。最常用三条：

- **看日志**：托盘右键 → 「打开日志目录」，或「设置 → 打开日志目录（诊断）」。
- **「壁纸切换失败」气泡**：随机到了一张损坏/被删的图，程序已自动换了下一张候选；
  3 张都失败才弹这条气泡。一般不用管。
- **换机 / 备份**：用「导出配置」把 JSON 拷过去，新机器「导入配置」即可。
